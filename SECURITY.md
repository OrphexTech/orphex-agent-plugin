# Security policy

## Reporting a vulnerability

Report a security issue in this plugin, or in the Orphex endpoint it connects to
(`https://api.orphex.co/api/interaction-gateway/v1/mcp`), by email to
[support@orphex.co](mailto:support@orphex.co) with "Security" in the subject line. Please
do not disclose it publicly until we have replied.

Include what you found, the steps to reproduce it, and the plugin version you used (the
`version` in `.claude-plugin/plugin.json`).

## Supported versions

Only the latest release is supported. Each release replaces the previous one, and a fix
ships as a new release.
